# 色彩科学说明

## 1. 为什么使用 Lab

RGB 欧氏距离与人的感知不一致，CIE Lab 更接近感知均匀空间。色墙的平均色、色差和选片都使用 Lab/LCh。

注意色相角不能跨空间混用：

| 颜色 | Lab 色相（近似） | HSV 色相（近似） |
|---|---:|---:|
| 红 | 40° | 0° |
| 黄 | 100° | 60° |
| 绿 | 136° | 120° |
| 蓝 | 280° | 240° |

因此：

- 色系池使用 `avg_LCh` 的 Lab 色相。
- `clean` 的像素覆盖率使用 HSV 色相。
- 不要把 HSV 的黄色 60° 与 Lab 的黄色核心带 85–115° 比较。

## 2. 平均色

1. 封面缩放到 96×96。
2. Median-cut 量化为 7 色。
3. 按像素占比对 7 个 Lab 色加权平均。
4. 由平均 `a/b` 计算彩度 `C` 和 Lab 色相 `h`。

用加权平均而不是最大色块，是为了减少纯色边框、白底或单个大色块对“封面主色”的支配。7 色是速度、抗噪和主色保留之间的折中，具体素材可以自行复测。

## 3. 干净度

```text
clean = 目标色带像素比 - 0.9 × 对立色像素比 - 0.7 × 过曝白像素比
```

它是排序/筛选特征，不是绝对的美学判断。默认不加硬筛。使用 `--min-clean` 会缩小池子，应根据用户图库重新验证阈值。

`--min-clean` 依赖索引中预定义颜色的 `clean` 字段，因此不能和自定义 `--hue` 同时使用；自定义色带请使用 `--cmin`。

## 4. 色散

`disp` 是 7 个量化色相对加权中心的加权标准差。

- 纯色或图形封面通常较低。
- 风景、渐变和细节丰富的封面可能很高，但观感不一定“脏”。
- 所以 `disp` 只作参考，不作为主筛选条件。

## 5. 感知亮度

排序主轴为：

```text
L + 0.25 × C
```

加入彩度项是为了近似饱和色的“显亮”效应。

极端黑底白字封面会让算术平均 L 偏向中灰，这是平均色方法的局限。不建议通过剔除近白/近黑来“修复”后再平均，因为大面积黑色在视觉上仍然会把封面整体压暗。

## 6. 2D 能量

```text
energy = 所有水平边和垂直边的 Lab 色差之和
```

N×N 墙共有：

```text
N × (N - 1) × 2
```

条邻接边。序号 4→5 在 4×4 网格中是换行，并不相邻，所以不能把墙当成一维序列优化。

当前实现：

1. 按 `L + 0.25×C` 全局降序铺入网格。
2. 只尝试同列上下交换。
3. 交换后必须仍满足行、列均不增。
4. 仅当 2D 能量下降时保留交换。

这是一种带硬单调约束的坐标下降，不保证全局最小能量。

## 7. gradient 的匈牙利分配

`gradient` 模式会：

1. 根据池内 L 的 5%–95% 分位生成 N² 个明度锚点。
2. 为每张候选封面计算锚点代价：
   - 明度差；
   - 与池中位色相的环形距离；
   - 与池中心 Lab 距离。
3. 用矩形匈牙利算法在候选池中选择 N² 张并完成一对一分配。

代价包含多个维度，因此不能简化成“按 L 排序后分段贪心等价”。当前实现使用全局最小代价分配。
## 8. 黑色为什么不用色相

黑色和深灰没有稳定的 Lab 色相：当 `a/b` 接近 0 时，色相角可能随机跳动。对黑色使用色相带会产生两个问题：

1. 近中性深色会被任意色相分到不同组。
2. 深红、深蓝、深绿可能被排除，即使视觉上已经接近黑色。

当前规则：

```text
L <= 28 且 C <= 40
```

- `L <= 28` 保证整体足够暗。
- `C <= 40` 防止深而鲜艳的颜色全部进入黑色池。
- `--relax N` 每级把 L 上限加 2、C 上限加 5，最大 4 级。

这是启发式规则，不是严格色彩分类。不同图库应通过真实出图复核阈值。

## 9. 歌手亲和度

从歌单推导喜爱歌手：

1. 按“歌名 + 歌手集合”去重。
2. 每位歌手出现在一首唯一歌曲中，计数 +1。
3. 合作曲中的每位歌手各计 1 次。
4. 按歌曲数降序生成歌手排名。

专辑没有直接的播放计数时，使用匹配到的最靠前歌手排名作为亲和度：

| 专辑关联歌手 | 匹配结果 |
|---|---|
| A（排名 1） | 使用排名 1 |
| A（排名 10）、B（排名 2） | 使用排名 2 |
| 无匹配 | 不参与喜爱首选，只能在颜色池中补位 |

这只是“用户可能喜欢什么”的代理信号。它不能证明用户更喜欢某张专辑，也不能替代用户手动指定。


## 10. 为什么严格核心池 + 自动放宽

不同颜色在 Lab 空间里的分布密度差异很大。同一套“宽色带”会导致红色、黄色池过大，而青色、紫色池过小；同一套“统一收紧”又会直接让青色无图可用。

因此 v1.3 使用两阶段策略：

1. 每个颜色有自己的严格核心色带和彩度下限。
2. 以 `N² + max(8, ceil(N²/2))` 作为建议池大小。
3. 不足时只按该颜色的步长放宽，最多 4 级。
4. 报告中记录每级实际生效阈值。

这样做的关键不是“尽量多收图”，而是：

- 默认输出先保证颜色语义干净；
- 不因尺寸变化直接无图可用；
- 需要放宽时保持可解释、可审计；
- 不把粉/品红向红色侧无限扩张。

自动放宽不是静默修改。真正生效的规则始终写入 `effective_rule`；需要完全严格时使用 `--no-auto-relax`，需要固定档位时使用 `--relax N`。
