# 测量与验收模板

本文件不包含任何真实用户、专辑或本机历史统计。公开分享技能时不要把你自己的索引、歌名、歌手名、排名或池子数量写进技能包。

## 建议记录的项目

| 项目 | 记录方式 |
|---|---|
| 测试日期 | 明确年份和日期 |
| 图库范围 | 只写数量或匿名类别，不写个人信息 |
| 图片格式 | JPG/PNG/WebP 等 |
| 索引耗时 | 包括图片数量和线程数 |
| 去重结果 | 重复组、剔除数、误判抽查结果 |
| 各色池大小 | 红/黄/绿/蓝等 |
| 出墙设置 | 尺寸、色系、模式、cell |
| 单调性 | `monotone=true` |
| 人工抽查 | 误删、标签可读性、明显杂色 |

## 可复现的自测

```bash
python scripts/selftest.py
```

自测使用临时生成的合成封面，不读取用户图库。需要查看产物时：

```bash
python scripts/selftest.py --keep
```

## 使用真实图库时的验收

1. 先告知用户将读取哪个目录，以及是否使用喜爱名单。
2. 记录索引成功数和跳过数。
3. 检查去重 `groups`，尤其注意黑白线稿、同模板封面和不同版本封面。
4. 检查输出 JSON 的 `pool`、`picked`、`monotone`。
5. 打开输出图检查标签是否只显示编号和专辑名，长标题是否能辨认。
6. 不要把测量结果中的真实专辑名、歌手名或排名提交到公开仓库。

## 黑色与喜爱口径回归

建议额外记录：

| 项目 | 检查方式 |
|---|---|
| 黑色池 | `L <= 28`、`C <= 40` 的候选数 |
| 黑色放宽 | 每级 L +2、C +5 后的池大小 |
| 歌手排名来源 | 歌单 / 手动名单 / 外部 JSON |
| 歌单唯一曲数 | 去重后的“歌名 + 歌手集合”数量 |
| 歌手覆盖 | `artist_rank_matches / indexed` |
| 喜爱首选 | 是否按歌手亲和度升序，而不是文件名 |
| 补位 | `filled_count` 与标签中的 `*` |

没有歌单或歌手排名时，只验收 `similar` / `gradient`，不要把普通专辑名排序当成喜爱模式。


## v1.3 颜色阈值验收

每次运行至少记录：

| 字段 | 含义 |
|---|---|
| `core_pool` | 严格核心色的数量 |
| `pool` | 自动放宽后的最终数量 |
| `relax_level` | 实际放宽级别，0 表示未放宽 |
| `auto_relaxed` | 是否发生自动放宽 |
| `auto_relax_target` | 建议余量目标 |
| `effective_rule` | 本次真正使用的色相/彩度或 black L/C 阈值 |

建议抽查：

1. 粉色墙有没有混入明显红色封面。
2. 紫色墙有没有混入明显蓝色封面。
3. 青色是否发生自动放宽，以及放宽后是否仍能辨认主色。
4. 同一颜色使用 `--no-auto-relax` 时是否仍满足当前尺寸。
5. `--relax N` 是否按预期固定档位。

不要把某一次图库的具体池子数量写成所有用户的默认期望。
